# SPU Stormwater Asset Map — Pioneer Square / SODO / Elliott Bay

Live map: **https://chriseshleman.github.io/spu-stormwater-map/** *(once GitHub Pages is enabled)*

Interactive web map of every Seattle Public Utilities (SPU) stormwater asset within a downtown Seattle bounding box — Pioneer Square, SODO, and the Elliott Bay waterfront. Roughly 18,000 features across 23 asset classes drawn at native geometry: pipes as polylines, basins as polygons, catch basins as points, and so on.

## What's on the map

- **Conveyance**: mainlines (active and force), SPU-owned non-mainlines, ditches & culverts, curb & gutter
- **Collection**: catch basins, sandboxes, junction boxes
- **Outfalls**: storm outfalls discharging into Elliott Bay
- **Detention**: vaults, ponds (none in this bbox), pump stations
- **Treatment**: water-quality structures (points and polygons)
- **Service areas**: CSO basins
- **Green stormwater infrastructure**: swales, underdrains, rain gardens, permeable pavement, weirs, facility footprints
- **Network points**: mainline end points, surface drainage points, appurtenance valves

Each layer can be toggled on or off via the controls in the top-right. Hover or click features for layer identification.

## Source data

All assets are derived from SPU's public ArcGIS Online services hosted at [Seattle GeoData](https://data-seattlecitygis.opendata.arcgis.com). Fetched via paginated REST API calls; full reproduction code lives in the companion analysis repo.

## Reproducing the map

The map is generated by a Python script that reads pre-filtered geographic-sample CSVs and produces a single self-contained `index.html` using the [Folium](https://python-visualization.github.io/folium/) library. To regenerate or change the bounding box, see the analysis repo.
